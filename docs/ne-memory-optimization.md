# NE 内存优化验证记录（2026-09-30）

本次包含 MRS 规则加载和连接历史采集两部分。节点 TOP、策略流量分布、主机名排行及详情页面保留；后台采样间隔仍为活跃连接 8 秒、已关闭连接 2 秒，每批上限仍为 256／512 条。App 关闭期间仍由 NE 记录，App 打开后计算排行。

## MRS 解码

对输出容量可确定且不超过 2 MiB 的单帧 MRS，使用有容量限制的一次性解码，避免为不足 1 MiB 的数据预留 8 MiB 历史窗口。大文件和特殊帧继续走原有流式路径；2 MiB 是优化路径的边界，不是规则文件大小限制。

51 个公开 MRS 文件的解压字节、规则数量、规则集序列化结果均与原实现一致。Windows/amd64、Go 1.25.4、GOMAXPROCS=4 下，整批顺序加载的累计分配从 57.52 MiB 降至 9.19 MiB，约减少 84%；耗时中位数从 11.49 ms 降至 10.69 ms。最大域名规则集单次加载慢约 0.43 ms，分配减少约 79%。完整细节见 `MobileCore/THIRD_PARTY_PATCHES.md`。

## 连接历史与排行榜

### 已修改

- NE 使用历史专用快照，仅编码存储层实际读取的字段。保留 ID、时间、流量、协议、地址、主机名、进程、完整策略链和规则字段；不再解析存储层未使用的 GeoIP、ASN、入站信息、provider 链等字段。App 查询连接详情时仍使用原有完整接口。
- Go 返回 `[]byte`，gomobile 直接桥接为 `NSData`／Swift `Data`，省去原先经过 Go 字符串、NSString 再转 UTF-8 Data 的过程。未宣称跨语言传输完全没有复制。
- 每批历史写入复用一条 SQLite 预编译语句和一个链编码器，逐条重置绑定、释放临时对象；不增加常驻连接明细缓存。
- 已关闭连接的最终流量与关闭状态一次提交，替代“先写为活跃，再另开事务标记关闭”。
- 只有成功提交后才推进关闭队列游标；临时写入失败会在下一轮重试。原有 512 条队列及其溢出行为仍然存在，不能保证极端短连接负载下绝不漏记。

### Go 侧测量

同一组合成连接记录，包含中文节点、IPv4／IPv6、策略链和大整数流量。Windows/amd64、Go 1.25.4、GOMAXPROCS=4、`with_low_memory`，每项测量 3 次、每次 500 ms，取中位数。

| 批次 | 原 JSON 字节 | 新 JSON 字节 | 原分配 B/op | 新分配 B/op | 原耗时 ms | 新耗时 ms |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 256 条 | 200721 | 122897 | 529019 | 253884 | 0.434 | 0.205 |
| 512 条 | 401425 | 245777 | 1121743 | 520454 | 0.843 | 0.409 |

JSON 约缩小 39%，Go 编码累计分配减少约 52%～54%。这些结果不包含 Swift JSON 解析和 SQLite 写入，不能直接作为整段采集流程或 NE 物理内存的降幅。

复现编码基准：在配置好 Mihomo 依赖补丁的 `MobileCore` 中运行：

```sh
go test -tags with_low_memory -run '^$' -bench BenchmarkHistorySnapshotEncoding -benchmem -count=3
```

### 验证范围

- Go 回归测试核对全部存储字段，覆盖中文、引号、IPv6、大整数、空 metadata／策略链和关闭队列字段；默认及 `with_gvisor,with_low_memory` 测试通过，后者 `go vet` 通过。
- 已生成 gomobile Objective-C 绑定，确认两个新接口均返回 `NSData* _Nullable`，对应 Swift 可选 `Data`。
- 从生产 Swift 文件提取实际 SQL，在本地 SQLite 验证 21 个绑定位置、活跃／关闭记录更新、重复提交不重复累加、整批失败回滚及流量总数。
- 新增 `scripts/test-connection-history.sh`，在 macOS 编译并运行实际 Swift 存储层，测试排行榜、批量写入、失败重试和 NE 聚合查询隔离；已接入 CI。本机为 Windows，尚未执行这套 Swift 测试或完整 Xcode 构建。

这些优化针对可确认的临时分配和重复工作。iOS 27 的断 VPN 原因仍需结合真机内存曲线和进程终止记录判断。
