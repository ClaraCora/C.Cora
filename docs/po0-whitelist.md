# PO0 白名单

设置 → 运行 → PO0 白名单。默认关闭，默认每 5 分钟检测；保存后即时同步到运行中的 VPN，无需重连。可选 1、3、5、10、15、30、60 分钟。最多 8 个 Token，用逗号、分号、竖线或空白分隔；支持参考脚本的 `pgnfw_xxx@0` 固定槽位形式。

检测使用参考脚本的 `POST https://124.221.69.228/api/firewall/<token>/add`，会将当前请求源 IP 加入白名单。请求直接绑定物理出口，不经过节点或分流规则，避免登记代理服务器的 IP。固定槽位可能替换该槽位已有 IP；403 会提示检查 Token 或在 PO0 网站处理槽位冲突。兼容字符串/对象两种白名单格式和 IPv4 `/24` 匹配。

## 生命周期与开销

- 定时任务在 NE 内的 Go 层执行，App 划掉后无需 App 唤醒。VPN 停止时取消请求、重试等待和定时器，并等待旧任务退出。
- 启动/保存启用设置后安排检测；物理网络变化会触发补检。连续事件合并，补检至少间隔 10 秒。常规间隔从上一轮完成后计算，系统调度及网络耗时可能让实际时间延后。
- 只有一个串行 worker，各 Token 依次请求；关闭功能时无 worker。无需常驻 JS 引擎或新的 Swift URLSession。
- 每次请求最多 15 秒、最多 3 次尝试，退避 1.5/3 秒。HTTP 响应体上限 32 KiB、响应头上限 16 KiB；最多展示 64 条白名单。只保留当前会话最近一轮结果。
- HTTP 连接不保活，保留 TLS 证书验证，禁止重定向。错误和状态不包含 Token 或请求 URL。
- 设置页面可见且 App 前台时轮询轻量状态；列表入口与子页面共用去重和节流。不会因打开页面重复发起网络检测。

这仍有少量 NE 常驻状态和请求期间的临时内存，不是零开销；没有真机测量前不声称具体内存增量。

## 保存与回退

Token 使用单独配置文件，目录权限 0700、文件权限 0600；iOS 采用首次解锁后可访问的文件保护，排除系统备份。配置不写入通用 UserDefaults、日志或状态接口。输入默认隐藏，切到后台重新隐藏。

共享容器可用时，系统/控制中心启动 VPN 会读取已保存设置。共享容器不可用时通过 App 启动 options 和运行期 IPC 传入 NE，并保存到扩展的本地缓存；在 VPN 断开时修改设置，需要下一次从 App 连接才能同步到扩展。该回退不会影响已经运行的 VPN 在 App 退出后继续检测。

## 验证

Go 测试覆盖格式校验、旧/新响应格式、`/24`、重试、403、响应大小、重定向限制、定时、停止、配置替换和切网合并。Swift 回归脚本 `scripts/test-po0-whitelist.sh` 编译实际配置存储和 App 控制器，覆盖配置保存、状态协议、同步失败重试与校验错误保留，已接入 macOS CI。

Windows 本地无法执行 Swift/Xcode/模拟器测试；实际 Token 加白、锁屏、强退 App 后持续运行及内存变化仍需 iPhone 验证。
